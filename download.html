System requirements

Runs on practically any Windows PC.

Windows 10 or 11

64-bit (x64), any edition.

OpenGL 2.0 graphics

Any GPU driver from roughly the last decade. The UI is hardware-accelerated.

A normal user account

No administrator rights. Everything installs to your own profile.

Browser (optional)

A current Chrome, Edge, Brave, Vivaldi, Opera or Firefox for automatic capture.

Browser integration

Set up the extension.

Until the extensions are listed on the Chrome Web Store and Firefox Add-ons, you install them by hand. It takes about a minute, and you only do it once: updates arrive automatically. Keep Zenless Download Manager running (and Zenless Torrent, if you use it) and the extension connects to it on its own.

Chrome, Edge, Brave, Vivaldi & Opera

Chromium-based browsers load the extension as an unpacked folder.

  1. Get the files. If you ticked the extension in Zenless Setup, it's already in %LOCALAPPDATA%\Programs\Zenless\Browser Extensions\Chrome: Setup's Show folder button opens Explorer with that folder selected. Otherwise download zenless-chrome-extension.zip and extract it to a folder you'll keep, because the browser loads it from there.
  2. Open the extensions page. Browsers don't open chrome:// links from websites or other apps (Zenless Setup included), so copy the address for your browser and paste it into the address bar: Ctrl+L, Ctrl+V, Enter.
    • chrome://extensionsChrome
    • edge://extensionsEdge
    • brave://extensionsBrave
    • vivaldi://extensionsVivaldi
    • opera://extensionsOpera
  3. Turn on Developer mode. The toggle is in the top-right corner in Chrome and Brave, and in the left sidebar in Edge.
  4. Drag the folder onto the page. Drop the Chrome folder (the one that contains manifest.json) anywhere on the extensions page. Or click Load unpacked and select it; you can paste the folder path into the picker's address bar.
  5. Pin it. Open the puzzle-piece menu next to the address bar and pin Zenless so it's one click away.

Updates are automatic. Zenless Download Manager keeps the folder from Zenless Setup up to date, and the extension reloads itself to pick up the new version. If it can't (for example, because you loaded a different folder), its popup says so: reload it from the extensions page.

Firefox

The Firefox add-on is awaiting Mozilla's signature. Regular Firefox only keeps signed add-ons installed, so until then you load it as a temporary add-on. It stays loaded until Firefox restarts.

  1. Get the file. Download zenless-firefox-extension.xpi. Zenless Setup can also save it to %LOCALAPPDATA%\Programs\Zenless\Browser Extensions.
  2. Open the debugging page. Firefox doesn't open it from links or other apps either, so copy it and paste it into the address bar:
    • about:debugging#/runtime/this-firefoxFirefox
  3. Load it. Click Load Temporary Add-on… and pick the .xpi. If the welcome page asks for site access, click Allow access.
  4. After a restart, load it again the same way. When a newer version is available, the Zenless popup tells you, and Reload on the same page picks it up.

Once the signed version is out, install it for good: open about:addons, click the gear icon, choose Install Add-on From File… and pick the .xpi. Firefox then keeps it up to date by itself. Firefox Developer Edition and Nightly can already keep the unsigned file installed once xpinstall.signatures.required is set to false in about:config.

Heads-up

Seeing “Windows protected your PC”?

Zenless 0.2 is brand new and isn't code-signed yet, so Microsoft Defender SmartScreen hasn't seen enough downloads to recognise it. That's normal for new open-source apps. To run it anyway:

  1. Click More info.
  2. Check that the app is ZenlessSetup.exe (or the app you downloaded), then click Run anyway.

Only run files you downloaded from github.com/zenless-inc or this site. Prefer to verify first? Releases are built by GitHub Actions from the public source, and you can build any app yourself with cargo build --release.
