The suite

Separate apps, not a bloated all-in-one.

Every Zenless app is its own small native program with its own window and settings. Take the download manager without the torrent client, or the other way round. They share one theme system and hand work to each other over localhost, and that's it.

Zenless Download Manager

zenless-dm.exe

Multi-connection downloads that make full use of your line, and pick up exactly where they left off, even after a reboot.

  • Up to 32 connections per file
  • Dynamic segmentation: finished connections split the biggest remaining part
  • Pause & resume across restarts
  • Download queue
  • Speed limiter
  • Automatic categories
  • Clipboard watch for copied links
  • Browser capture via the extension
  • Live segment map per download
  • 34 themes + custom themes
  • Automatic updates, installed when you close the app
  • Lives in the system tray, with quick actions
  • Keeps the installed Chrome extension up to date

Themes

Thirteen themes. One click. Every app.

Every Zenless app ships the same 34 palettes, and so does this page. Pick one and the whole site re-colors itself, the same way the apps do.

Your theme here Tweak all 15 colors, text size, rounding and density in Settings → Appearance.

Custom themes are shared by every app. Make one in any Zenless app and it's saved to %APPDATA%\Zenless\themes. The download manager, torrent client and installer all pick it up, and running apps switch live when you change it. No restart needed.

Built with Rust

Native, tiny and memory-safe.

No Electron, no bundled browser, no runtime to install. Each Zenless app is a single native .exe of a few megabytes that starts instantly and stays out of your way.

  • egui / eframeGPU-accelerated immediate-mode UI. Crisp at any DPI and themeable down to the last pixel.
  • tokioAsync I/O that keeps dozens of connections busy on a couple of threads.
  • librqbitA fast BitTorrent engine written in Rust, at the heart of Zenless Torrent.
  • reqwest + native TLSHTTP/2 and HTTPS through Windows' own SChannel, so there's no OpenSSL to patch.
# excerpt
[package]
name = "zenless-dm"
version = "0.1.0"
edition = "2024"
license = "MIT"

[dependencies]
eframe = "0.36"      # native GPU UI (egui)
tokio = "1"         # async connections
reqwest = "0.13"     # HTTP/2 + SChannel TLS
tiny_http = "0.12"   # 127.0.0.1 API for the extension
serde_json = "1"    # plain-JSON settings

[profile.release]
lto = "thin"
strip = true
panic = "abort"

Privacy

Your downloads are nobody else's business.

Zenless has no servers to phone home to. The browser extension only ever talks to the Zenless apps running on your own PC, over 127.0.0.1.

  • No telemetry, no analyticsNothing about you or your downloads is collected or sent anywhere.
  • No accounts, no adsDownload, install, use. That's the whole relationship.
  • A locked-down local APIThe apps listen on localhost only and reject requests from web pages. Only browser extensions get through.
  • Your settings stay on your diskPlain JSON files in %APPDATA%\Zenless. Open them, back them up, delete them.

FAQ

Questions, answered.

Something else? Open an issue on GitHub and we'll get back to you.

Why separate apps instead of one?

Because most people only need one of them. Separate apps stay small, start fast and can't drag each other down: a stuck torrent never slows a download, and updating one never touches the other.

They still work as a team. They share one theme system, and the browser extension sends magnet links to Zenless Torrent and everything else to the Download Manager.

Does the browser extension send my data anywhere?

No. It only talks to the Zenless apps on your own computer, at 127.0.0.1 (ports 6812 and 6813). When it hands over a download it passes the link plus what the website needs to allow it (the referrer, that site's cookies and your user agent) to the local app, which then downloads the file directly.

No analytics, no remote server, no account. Details are in the privacy policy.

How do I install the Chrome extension?

Until it's listed on the Chrome Web Store, you load it yourself. It takes about a minute:

  1. Use the copy Zenless Setup put in %LOCALAPPDATA%\Programs\Zenless\Browser Extensions\Chrome (Setup's Show folder button highlights it), or download zenless-chrome-extension.zip and unzip it.
  2. Paste chrome://extensions into the address bar. Browsers don't open these addresses from links or other apps. In other browsers use edge://extensions, brave://extensions, vivaldi://extensions or opera://extensions.
  3. Switch on Developer mode.
  4. Drag the folder that contains manifest.json onto the page (or click Load unpacked and pick it).
  5. Pin Zenless from the puzzle-piece menu so it's one click away.

You only do this once: the Download Manager keeps Setup's copy up to date and the extension reloads itself. There's a step-by-step guide on the download page.

What about Firefox?

The Firefox add-on is awaiting Mozilla's signature, and regular Firefox only keeps signed add-ons installed. Until it's signed, download zenless-firefox-extension.xpi, paste about:debugging#/runtime/this-firefox into the address bar, click Load Temporary Add-on… and pick the file. It stays active until Firefox restarts.

Once the signed version is out, install it from about:addons → gear icon → Install Add-on From File…, and Firefox keeps it up to date by itself.

How do updates work?

The Download Manager and Torrent check GitHub for a new release every few hours, download it in the background, verify its checksum and install it when you close the app (or right away, if you click Restart now). You can turn this off in Settings → About → Updates.

The Download Manager also refreshes the browser extension that Zenless Setup installed. The Chrome extension then reloads itself; Firefox shows a notice in the Zenless popup.

Is it really free?

Yes. Every Zenless app is open source under the MIT license: free for personal and commercial use, with no trials, no ads and no "pro" tier. If you like it, a star or a bug report on GitHub helps a lot.

Windows says "Windows protected your PC". Is it safe?

Zenless 0.2 is new and not code-signed yet, so Microsoft SmartScreen doesn't recognise it. Click More info → Run anyway. Only download Zenless from github.com/zenless-inc or this site. If you'd rather not trust a binary at all, build it from source.

Do I need administrator rights?

No. Zenless Setup installs just for you into %LOCALAPPDATA%\Programs\Zenless and only writes to your own part of the registry (HKCU), for things like autostart and magnet links. You won't see a UAC prompt.
